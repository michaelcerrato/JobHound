# JobHound

JobHound is an evolving job application tracking and job-matching application. The project is being developed to explore modern application development technologies, beginning with an ASP.NET Core Web API and Entity Framework Core.

The initial version focuses on tracking job applications and managing their associated information. Future development will expand the application with a React frontend and Python-based functionality to analyze job descriptions, compare them against a user's professional profile, and identify how closely a candidate's experience and skills align with a position.

## Project Goals

- Build a modern REST API using ASP.NET Core.
- Explore Entity Framework Core for data access and database management.
- Develop a React and TypeScript frontend.
- Incorporate Python for job description analysis and profile matching.
- Eventually provide insights into how well a candidate's skills, experience, and background match specific job opportunities.
